Le Vestiaire

Comment s'habiller, événement par événement. Être mal habillée, c'est se voir refuser la porte : le dress code fait partie de la voie d'entrée.

Les tenues ci-dessous sont celles que les organisateurs publient ou exigent, relevées fiche par fiche. Quand un événement n'apparaît pas ici, c'est que son code vestimentaire n'est pas publié : dans le doute, l'élégance sobre ne se refuse nulle part.
